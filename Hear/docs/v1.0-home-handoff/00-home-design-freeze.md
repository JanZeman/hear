# Home design freeze

## 1. Logo
Use only the supplied locked logo files in `assets/brand/`.

Never redraw the logo.
Never rebuild it from primitive shapes in Unity.
Never change spacing.
Never change the 4-element system.

The static HEAR mark is always:
- dot over H
- small ellipse over E
- medium ellipse over A
- large ellipse over R

## 2. Claim
`Sound opens worlds.` is rendered separately as UI text.
It is not baked into the logo asset.

## 3. Companion
Companion is a separate sprite, not part of the world art.
It has no feet.
Grounding happens with the provided separate shadow asset.

## 4. Home structure
Home is not a dashboard.
It is an immersive world selector.

Required structure:
- world atmosphere filling the viewport
- HEAR brand moment at the top
- one central selected world card
- neighboring cards peeking left/right
- page dots
- one Play action
- subtle bottom navigation (compact) or restrained sidebar (wide desktop)

Forbidden structure:
- giant hero panel + separate thumbnail row
- profile/avatar/greeting filler
- `FEATURED WORLD`
- generic gray/beige shell

## 5. Bottom navigation
Bottom navigation sits over the scene.
It may use very subtle darkening / glow for legibility.
It must not become a plain solid white or black bar.

## 6. Responsive behavior
The visual language stays the same across Android and iOS.
Only safe areas / insets differ.
