# HEAR Companion Production Assets v1.0

This package is the canonical runtime Companion source.

## Frozen appearance
- No visible feet.
- No legs.
- No protruding toes/base.
- One smooth continuous pearl/aurora body.
- Two minimal luminous oval eyes.
- No baked floor/contact shadow.
- Grounding shadow is supplied separately.

## Themes
Use `on-dark` for cinematic/dark world backgrounds.
Use `on-light` for white/light UI backgrounds.

The character identity and geometry are the same in both themes; only contrast/rim treatment changes.

## Left/right
Use a supplied right-facing sprite when the Companion is placed on the left side of the UI.
Use a supplied left-facing sprite when placed on the right side, so it generally looks inward.

## Poses
- neutral-left/right
- upright-left/right
- listening-left/right
- curious-left/right

Each pose is exported at 1024, 512 and 256 px.

## Shadows
Use shadows separately. Never paint a new floor/base under the Companion.
The shadow may be scaled proportionally and have opacity adjusted per surface.

## Important
Do not redraw or regenerate the Companion in Unity.
Do not crop it from moodboards.
Do not add feet.
Do not merge it permanently into Home backgrounds.
