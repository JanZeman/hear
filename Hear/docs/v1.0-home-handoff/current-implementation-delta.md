# Current implementation: required corrections

Compared with the GOLDEN concept board, the current implementation shown by the user is wrong in these specific ways:

1. Home is a generic dashboard rather than an immersive world selector.
2. There is no proper HEAR brand/claim composition at the top.
3. Background is a flat/blurred shell instead of a sharp continuation of the active world.
4. `FEATURED WORLD` is not part of the approved Home.
5. River Journey title is far too large and wraps; approved title is compact, one line where space allows.
6. Center hero behaves like a large content panel, not a carousel card.
7. The lower three-card thumbnail row is wrong; neighbors must peek from the carousel edges.
8. World names are truncated; never acceptable.
9. Companion is visually pasted onto/over the hero and has grounding/artifact problems.
10. Bottom navigation is too tall, bright and dashboard-like.
11. Profile/greeting/avatar concepts are not product requirements.
12. The whole screen leaves too much dead shell area instead of allowing the world to fill the viewport.

Fix these structurally, not by tweaking font sizes only.
