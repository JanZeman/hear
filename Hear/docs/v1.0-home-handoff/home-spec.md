# Home screen exact direction

## Visual hierarchy
1. Active world atmosphere fills the whole viewport.
2. HEAR mark + wordmark centered high on the screen.
3. `Sound opens worlds.` immediately below, readable.
4. Center world card dominates.
5. Previous/next cards peek from the sides.
6. Page dots.
7. Companion feels physically present but is a separate sprite.
8. One Play pill.
9. Minimal navigation.

## Background
No blur as the main visual treatment.
The background should be the active world's own sharp artwork with atmospheric grading/darkening so UI remains legible.

## Logo
Never generate/redraw it.
Use the supplied SVG/PNG.

The first visual element is part of the approved mark; do not invent a four-colored-ellipse substitute.

## Claim
Render as text. Compact/mobile target: 18 logical px. Never shrink it into decorative microcopy.

## Companion
Use `companion-river-neutral.png`.
Use `companion-soft-shadow.png` separately.
Do not use a hard rectangle, artifact, opaque floor, or clipped base.
Do not place it over the center hero subject.

## Carousel
No separate thumbnail gallery.
Neighbors are partial peeks of the carousel itself.

## Evaluation
The GOLDEN board is the acceptance reference.
A technically valid screen that still reads as a generic dashboard is a visual failure.
